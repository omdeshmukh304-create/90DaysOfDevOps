# Day 90 – Graduation 🎉

## My 90 Days of DevOps Journey

Today marks Day 90 of my DevOps journey.

When I started this challenge, I only knew a few basic Linux commands. I had no idea how tools like Docker, Kubernetes, Terraform, or GitOps worked together. My goal was simple: stay consistent, learn every day, and build everything with my own hands.

Looking back, I can confidently say that these 90 days completely changed the way I think about software development and infrastructure.

---

# My 90-Day Timeline

## Week 1-2 – Linux Fundamentals

I started with Linux basics like file management, permissions, processes, users, and system administration.

At first, commands like `ls`, `chmod`, `grep`, and `systemctl` felt new, but after practicing daily they became part of my workflow.

**What I learned:** Linux is the foundation of DevOps.

---

## Week 3 – Networking

I learned about IP addresses, DNS, ports, subnets, and how systems communicate with each other.

This helped me understand why applications sometimes fail to connect and how networking affects deployments.

---

## Week 4 – Shell Scripting

Instead of repeating commands manually, I learned how to automate tasks using Bash scripts.

I wrote scripts using variables, loops, conditions, and functions.

This was my first step into automation.

---

## Week 5 – Git & GitHub

I learned how developers collaborate using Git.

I practiced commits, branches, merges, pull requests, and working with GitHub repositories.

Now every project I build is version controlled.

---

## Week 6 – Docker

Docker completely changed the way I think about applications.

I learned how to build Docker images, write Dockerfiles, use Docker Compose, manage volumes, and create multi-container applications.

The idea of packaging an application with all its dependencies finally made sense.

---

## Week 7-8 – CI/CD with GitHub Actions

I automated builds and deployments using GitHub Actions.

Instead of running everything manually, I created workflows that automatically built Docker images and pushed them to Docker Hub whenever I pushed code.

Watching the pipeline complete successfully for the first time was a great feeling.

---

## Week 9 – Kubernetes

This was one of the most challenging parts of the journey.

I learned about Pods, Deployments, Services, ConfigMaps, Secrets, Namespaces, and RBAC.

It took time to understand how everything worked together, but after lots of practice it finally clicked.

---

## Week 10 – Terraform

Terraform introduced me to Infrastructure as Code.

Instead of creating cloud resources manually, I learned how to define infrastructure using code and let Terraform provision it automatically.

This changed the way I think about cloud infrastructure.

---

## Week 11 – Ansible

I learned how to automate server configuration using Ansible.

Creating inventories, writing playbooks, using roles, and managing configurations made server administration much easier.

---

## Week 12 – Observability

I deployed Prometheus, Grafana, Loki, and OpenTelemetry.

For the first time, I could actually monitor an application, view dashboards, inspect logs, and understand what was happening inside the cluster.

I realized that deploying an application is only half the job—monitoring it is equally important.

---

## Week 13 – Helm

I converted Kubernetes manifests into reusable Helm charts.

I also created different values files for development, staging, and production environments.

This made deployments much cleaner and easier to manage.

---

## Week 14 – Amazon EKS

I provisioned an Amazon EKS cluster using Terraform and deployed applications on it.

Working with a managed Kubernetes cluster gave me experience with production-style deployments.

---

## Week 15 – ArgoCD & GitOps

I learned how GitOps works and configured ArgoCD to automatically deploy changes from Git.

Instead of running deployment commands manually, Git became the single source of truth.

---

## Final Days – Agentic AI for DevOps

The last few days introduced me to AI-powered operations.

I explored concepts like AI agents, MCP, Temporal, and KubeHealer.

It gave me a glimpse into where DevOps is heading in the future.

---

# My Top 5 Aha Moments

### 1. Everything connects together.

At first every tool looked independent, but by the end I understood that every topic builds on the previous one.

### 2. Docker and Kubernetes finally made sense.

Docker packages applications, while Kubernetes keeps them running reliably.

### 3. Git became much more than version control.

It became the starting point for CI/CD and GitOps workflows.

### 4. Infrastructure can be treated like software.

Terraform showed me that cloud infrastructure can be version controlled and automated.

### 5. Monitoring is essential.

Metrics, logs, and traces help explain why applications behave the way they do.

---
